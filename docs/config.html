EchoPort 配置参考 config.lua

用一份可选的 Lua 5.4 文件定制 EchoPort：界面语言与主题、启动页面、缩放、音量、搜索与下载、缓存、键盘快捷键、播放步长，以及事件钩子与自定义动作。所有设置都是可选的，非法值只会产生警告，不会让应用崩溃。

v0.1.6 Lua 5.4 · 无需安装 Lua 本地文件 · 不上传 设置页 → 重新加载脚本 生效

1. 快速开始

首次启动且文件不存在时，EchoPort 会自动生成一份全注释的模板（不会覆盖已有文件）。编辑后从 设置 → 重新加载脚本 生效。

-- ~/.config/echoport/config.lua  (Linux)
-- %APPDATA%\echoport\config.lua   (Windows)
echoport.config = {
  language = "zh",          -- 界面语言 / UI language
  theme = "ink",            -- 主题 / theme
  ui_scale = 1.25,          -- 界面缩放 / UI zoom
  startup_page = "search",  -- 启动页面 / startup page
  volume = 0.6,             -- 初始音量 / initial volume
  keyboard = {
    ["Space"] = "play_pause",
    ["Ctrl+ArrowRight"] = "next",
  },
}
提示：只写你想改的键即可，其余保持注释或用档案默认值。配置文件以你的用户权限在本机执行，属于受信任的本地脚本，不是沙箱。

2. 文件位置与生效方式

平台配置文件插件目录
Linux~/.config/echoport/config.lua~/.config/echoport/plugins/
macOS~/Library/Application Support/echoport/config.lua…/echoport/plugins/
Windows%APPDATA%\echoport\config.lua%APPDATA%\echoport\plugins\
  • 首次运行：目录和模板自动创建；已有 config.lua 永远不会被覆盖。
  • 修改后：设置 → 重新加载脚本（或重启应用）。重新加载会重建整个 Lua 状态并重新执行所有插件。
  • 重新加载失败：例如 Lua 语法错误，会保留上一次成功的配置与插件，并在设置页显示一条警告。
  • 恢复默认：删除 config.lua 后下次启动会重新生成模板（插件不受影响）。
  • 警告上限：设置页最多显示 100 条脚本警告，避免刷屏。

3. 全部选项

所有键都写在 echoport.config = { ... } 表里；全部可选。类型不符或越界的值会得到一条警告，并按“截断/忽略”处理。

键 / key类型默认说明
language字符串系统语言"en" / "zh"
startup_page字符串homehome、search、library、playlists、downloads、now_playing、artist、profile、settings
ui_scale数字1.0界面缩放，范围 0.8–2.0；设置页预设 100% / 110% / 125% / 150%
volume数字0.72初始音量 0–1，越界截断
theme字符串pulsepulse / tide / ink；旧别名见第 4 节
follow_cover_accent布尔true是否跟随当前封面取色
accent颜色主题色强调色，如 "#044BB5"
highlight颜色主题色荧光高亮色，如 "#BBFF5C"
macaron表内置五色正好 5 个颜色字符串
seek_step数字5.0快进/快退步长（秒），1–120
volume_step数字0.05音量键步长，0.01–0.5
results_per_platform整数12每个平台的搜索结果数，2–50
download_format字符串mp3mp3 / m4a / opus / flac
download_dir路径~/Music/EchoPort下载目录，支持 ~ 与 $VAR
music_dirs路径表{ "~/Music" }本地曲库扫描目录，至少 1 个
cache_limit_mb整数1024音频缓存上限（MiB），0–10240；0 = 不保留已播放缓存；设置页预设 0 / 512 / 1024 / 2048
keyboard表内置快捷键[按键] = 动作；值也可以是函数，见第 5 节
提示：ui_scale 与 cache_limit_mb 在 v0.1.6 起可由 Lua 配置；在设置页修改会把值写回个人档案。未知键（plugins、custom、hooks 三个命名空间除外）会得到一条 unknown setting 警告。

4. 取值格式

主题

值说明
pulse默认：瓷白 + 亮蓝 + 荧光青柠高亮
tide浅水青 + 湖蓝 + 深海军蓝
ink低饱和深色石板
旧别名blue_white / album / porcelain → pulse；midnight → ink

颜色

接受 "#RGB"、"#RRGGBB"、"#RRGGBBAA"（# 可省略，也接受 0x 前缀）。macaron 必须正好 5 个颜色，否则整项忽略并警告。

路径

开头 ~/（或 ~\）展开为家目录；$VAR / ${VAR} 展开环境变量，未定义的变量保持原样。示例："~/Music/EchoPort"。

页面

home · search · library · playlists · downloads · now_playing · artist · profile · settings（也接受 now-playing、nowplaying 等写法）。

5. 键盘快捷键

写法：["按键组合"] = "动作"。修饰键大小写不敏感，可用 Ctrl Alt Shift Cmd（Windows/Linux 上 Cmd 等价于 Ctrl）。

echoport.config = {
  keyboard = {
    ["Space"] = "play_pause",
    ["Ctrl+ArrowRight"] = "next",
    ["Ctrl+ArrowLeft"] = "previous",
    ["Ctrl+Shift+F"] = "toggle_favorite",
    ["Ctrl+Alt+J"] = "action:hello",         -- 自定义动作 / custom action
    ["Ctrl+Alt+M"] = function()               -- 也可以直接写函数 / function value
      echoport.notify("键盘函数回调 / keyboard function fired")
    end,
  },
}

内置动作

动作名作用动作名作用
play_pause播放 / 暂停next下一首
previous上一首seek_forward向前快进
seek_backward向后快退volume_up音量 +
volume_down音量 −toggle_queue显示/隐藏队列
toggle_favorite收藏当前曲目toggle_shuffle随机播放
cycle_repeat循环模式open_search搜索页
open_settings设置页open_home主页

按键名

Space、A–Z、0–9、F1–F35、ArrowLeft/Right/Up/Down（可写 Left…）、Esc/Escape、Enter、Tab、Backspace、Delete、Insert、Home、End、PageUp/PgUp、PageDown/PgDn、Comma、Period、Slash、Backslash、Minus、Plus、Equals、Backtick 等。

优先级：输入框聚焦时快捷键会被抑制，避免打字触发播放。重复的按键组合以后注册的为准，并记录一条警告；自定义动作写作 "action:<id>"。

6. 自定义动作与绑定

动作会出现在设置页的脚本动作列表里，可被 keyboard 或 echoport.bind 引用。

-- 注册一个动作 / register an action
echoport.actions.add({
  id = "focus_mode",                -- 必填、唯一 / required, unique
  title = "专注模式 / Focus mode",  -- 必填 / required
  description = "音量降到 30% 并暂停", -- 可选 / optional
  keys = "Ctrl+Alt+F",              -- 可选：字符串或字符串表
  run = function()
    echoport.set_volume(0.3)
    echoport.command("play_pause")
    echoport.notify("专注模式已开启 / focus mode on")
  end,
})

-- 绑定快捷键 / bind keys
echoport.bind("Ctrl+Alt+N", "next")
echoport.bind("Ctrl+Alt+D", function()
  echoport.notify("自定义绑定 / custom binding")
end)

纯配置也可以不写任何代码，只设置上面的选项表；事件钩子与完整 Lua API 见 docs/plugins.html。

7. 完整示例

可直接复制替换整个 config.lua（所有值都合法）：

echoport.config = {
  language = "zh",
  startup_page = "home",
  ui_scale = 1.1,
  volume = 0.72,

  theme = "pulse",
  follow_cover_accent = true,
  accent = "#044BB5",
  highlight = "#BBFF5C",
  macaron = { "#BBCFF5", "#C3E9EA", "#F9E7A6", "#D9CCF2", "#FAD3B8" },

  seek_step = 5.0,
  volume_step = 0.05,
  results_per_platform = 12,
  download_format = "mp3",
  download_dir = "~/Music/EchoPort",
  music_dirs = { "~/Music" },
  cache_limit_mb = 1024,

  keyboard = {
    ["Space"] = "play_pause",
    ["Ctrl+ArrowRight"] = "next",
    ["Ctrl+ArrowLeft"] = "previous",
    ["Ctrl+Alt+Q"] = "toggle_queue",
  },
}

-- 可选：事件钩子（详见 docs/plugins.html）
echoport.on("track_start", function(track)
  if track ~= nil then
    echoport.log("playing: " .. track.title)
  end
end)

EchoPort config reference config.lua

Customize EchoPort with an optional Lua 5.4 file: UI language and theme, startup page, zoom, volume, search and downloads, cache limit, keyboard shortcuts, playback steps, plus event hooks and custom actions. Every setting is optional and invalid values only produce warnings — never a crash.

v0.1.6 Lua 5.4 · nothing to install Local file · never uploaded Apply: Settings → Reload scripts

1. Quick start

On first run, when the file does not exist, EchoPort writes a fully commented template (it never overwrites an existing file). Apply edits with Settings → Reload scripts.

-- ~/.config/echoport/config.lua  (Linux)
-- %APPDATA%\echoport\config.lua   (Windows)
echoport.config = {
  language = "en",          -- UI language / 界面语言
  theme = "ink",            -- theme / 主题
  ui_scale = 1.25,          -- whole-UI zoom
  startup_page = "search",  -- startup page
  volume = 0.6,             -- initial volume
  keyboard = {
    ["Space"] = "play_pause",
    ["Ctrl+ArrowRight"] = "next",
  },
}
Tip: only write the keys you want to change; everything else stays commented out and keeps the profile default. The config file runs locally with your user permissions: it is trusted local code, not a sandbox.

2. File locations & reloading

PlatformConfig filePlugin folder
Linux~/.config/echoport/config.lua~/.config/echoport/plugins/
macOS~/Library/Application Support/echoport/config.lua…/echoport/plugins/
Windows%APPDATA%\echoport\config.lua%APPDATA%\echoport\plugins\
  • First run: directories and the template are created automatically; an existing config.lua is never overwritten.
  • After editing: Settings → Reload scripts (or restart). Reloading rebuilds the entire Lua state and re-executes all plugins.
  • Failed reload: a syntax error, for example, keeps the previous working configuration and plugins, and surfaces a warning in Settings.
  • Reset: deleting config.lua recreates the template on the next start (plugins are untouched).
  • Warning cap: Settings shows at most 100 script warnings.

Every key lives inside the echoport.config = { ... } table and is optional. Wrong types or out-of-range values produce a warning and are clamped / ignored.

4. Value formats

Themes

ValueDescription
pulsedefault: porcelain white + vivid blue + fluorescent lime highlight
tidelight aqua + teal + deep navy
inklow-saturation dark slate
legacyblue_white / album / porcelain → pulse; midnight → ink

Colours

Accepts "#RGB", "#RRGGBB", "#RRGGBBAA" (the # may be omitted and 0x is accepted). macaron must contain exactly five colours, otherwise the whole value is ignored with a warning.

Paths

A leading ~/ (or ~\) expands to your home directory; $VAR / ${VAR} expand environment variables (unknown variables are left untouched). Example: "~/Music/EchoPort".

Pages

home · search · library · playlists · downloads · now_playing · artist · profile · settings (spelling variants such as now-playing and nowplaying are accepted).

5. Keyboard shortcuts

Syntax: ["chord"] = "action". Modifiers are case-insensitive: Ctrl Alt Shift Cmd (Cmd == Ctrl on Windows/Linux).

echoport.config = {
  keyboard = {
    ["Space"] = "play_pause",
    ["Ctrl+ArrowRight"] = "next",
    ["Ctrl+ArrowLeft"] = "previous",
    ["Ctrl+Shift+F"] = "toggle_favorite",
    ["Ctrl+Alt+J"] = "action:hello",         -- custom action
    ["Ctrl+Alt+M"] = function()               -- function value is allowed too
      echoport.notify("keyboard function fired / 键盘函数回调")
    end,
  },
}

Built-in actions

ActionEffectActionEffect
play_pauseplay / pausenextnext track
previousprevious trackseek_forwardseek forward
seek_backwardseek backwardvolume_upvolume +
volume_downvolume −toggle_queuetoggle queue panel
toggle_favoritefavourite current tracktoggle_shuffleshuffle
cycle_repeatcycle repeat modeopen_searchopen search
open_settingsopen Settingsopen_homeopen Home

Key names

Space, A–Z, 0–9, F1–F35, ArrowLeft/Right/Up/Down (or Left…), Esc/Escape, Enter, Tab, Backspace, Delete, Insert, Home, End, PageUp/PgUp, PageDown/PgDn, Comma, Period, Slash, Backslash, Minus, Plus, Equals, Backtick, and more.

Precedence: shortcuts are suppressed while a text field has keyboard focus so typing never triggers playback. Duplicate chords keep the last registration and log a warning. Custom actions are referenced as "action:<id>".

6. Custom actions & bindings

Actions appear in the Settings script-action list and can be referenced from keyboard or echoport.bind.

-- register an action / 注册一个动作
echoport.actions.add({
  id = "focus_mode",                  -- required, unique / 必填、唯一
  title = "Focus mode",               -- required / 必填
  description = "volume 30% + pause", -- optional / 可选
  keys = "Ctrl+Alt+F",                -- optional string or list of strings
  run = function()
    echoport.set_volume(0.3)
    echoport.command("play_pause")
    echoport.notify("focus mode on / 专注模式已开启")
  end,
})

-- bind keys / 绑定快捷键
echoport.bind("Ctrl+Alt+N", "next")
echoport.bind("Ctrl+Alt+D", function()
  echoport.notify("custom binding / 自定义绑定")
end)

A config file can also stay code-free and only use the option table; see docs/plugins.html for event hooks and the full Lua API.
