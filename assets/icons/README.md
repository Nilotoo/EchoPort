# EchoPort icon assets

These icons were supplied by the EchoPort project owner and are used for the
in-app UI (navigation, actions, player controls) wherever a matching glyph
exists. They come in two stroke colours (black / white) with PNG sizes 24, 48,
128 and 256 plus SVG sources.

- Author: Singular Programmer
- License: MIT No Attribution (MIT-0) — see `LICENSE.txt` in this folder.
- Usage in EchoPort: the white PNG variants are embedded into the binary and
  tinted with the active theme colour (so they work on light and dark themes);
  the black variants are kept for future/export use. The app/launcher icon is
  currently still the original EchoPort brand icon and can be swapped to one of
  these assets later if desired.
